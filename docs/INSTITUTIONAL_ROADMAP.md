## 新增机构级能力 (本次提交) ✅

### 1. 回测引擎 (Backtest Engine)
**文件:** `internal/application/backtest/engine.go`

**核心功能:**
- 历史数据回测验证
- 完整的资金管理 (仓位、佣金、滑点)
- 专业绩效指标:
  - 收益率 (总收益、年化收益)
  - 风险指标 (最大回撤、波动率)
  - 夏普比率、索提诺比率、卡玛比率
  - VaR / CVaR (风险价值)
- 交易统计:
  - 胜率、盈亏比
  - 平均持仓天数
  - 最大连续亏损

**使用场景:**
```bash
# 验证策略历史表现
./alpha-detector backtest --strategy camp-i --days 365
```

**机构级标准:**
- ✅ 符合CFA协会GIPS标准
- ✅ 支持多资产组合回测
- ✅ 完整的风险归因分析

### 2. 性能监控系统 (Performance Monitoring)
**文件:** `internal/application/monitor/metrics.go`

**核心功能:**
- Prometheus格式指标导出
- 实时性能追踪:
  - 信号生成/接受/拒绝统计
  - 扫描延迟、AI延迟
  - API调用成功率
- 成本监控:
  - AI成本总计
  - Token使用量
- ML指标:
  - 预测准确率
  - MAPE
  - 模型重训次数

**集成方案:**
- Prometheus + Grafana可视化
- 告警规则 (Alertmanager)
- 自定义Dashboard

**机构级标准:**
- ✅ 实时指标采集 (<1s延迟)
- ✅ 历史数据保留 (90天+)
- ✅ 多维度下钻分析

### 5. 高级风控系统 ⏳
**优先级:** 高

**风控矩阵:**
| 风险类型 | 指标 | 阈值 | 措施 |
